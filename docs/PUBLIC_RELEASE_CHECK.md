# 公开发布检查清单

每次公开仓库或发布版本前，针对实际准备上传的分支、标签和文件执行检查。此清单不代表某个版本已通过审核。

## 隐私与历史

- [ ] 检查全部待发布历史中的作者/提交者身份、提交说明、文件内容和路径，使用适合公开的 Git 身份。
- [ ] 确认没有邮箱凭证、访问令牌、私钥、个人联系方式、私人文档链接或个人目录信息。
- [ ] 确认数据库、原始邮件、日志、审计输入输出、截图和本机备份没有入库；检查历史，不能只看当前 `.gitignore`。
- [ ] 逐项人工复核扫描命中，区分真实信息、虚构测试数据和通用示例；不要只根据扫描数量判定安全。

```powershell
python tools/audit_public_history.py
git status --short
git ls-files
```

审计覆盖全部 Git 引用的可达历史，不包含 reflog、悬空对象和被忽略的本机文件。详细报告只在被忽略的本机目录中保存。规则扫描不能识别所有隐私或任意格式的密钥，需要人工复核。

## 安装与功能

- [ ] 在独立目录按 README 完成全新安装，配置示例不包含真实账户信息。
- [ ] 核对支持的操作系统、Python 和 CodeBuddy CN CLI 版本，以及模型权限要求。
- [ ] 明确哪些脚本只适用于旧部署，避免新用户误执行迁移或覆盖已有数据。
- [ ] 验证初始化拒绝覆盖已有数据，检查邮件去重、完成状态、备注和手动日程的保存行为。
- [ ] 运行离线测试，并确认测试不会连接真实邮箱、调用模型或修改使用中的计划任务。

## 说明与许可

- [ ] 说明邮件内容会交由模型服务处理、本机数据存储位置、加密边界和备份方式。
- [ ] 核对开源许可证、复用代码的发布权利及所需版权声明。
- [ ] 确认 README、配置示例与实际行为一致，清楚列出已知限制。

## 发布范围

- [ ] 核对目标远端、分支和标签，只发布审核过的内容。
- [ ] 不上传本机运行目录、历史恢复备份或包含私人信息的目录压缩包。
- [ ] 检查最终差异与工作区状态，另获发布授权后再上传。
