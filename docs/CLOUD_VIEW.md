# 在线只读副本

Sites 复用 app/web 的原界面，展示最后同步的日历、步骤、邮件提取结果、备注和手动日程。原邮件正文、模型输入输出及邮箱凭证不上传；文本中的网页链接、邮箱和手机号脱敏。判断审计仅同步状态摘要。

本机 `cloud-sync.dpapi` 仅位于被忽略的运行目录，使用当前 Windows 用户 DPAPI 加密，保存 Site 地址和服务上传凭证。不得提交或公开。配置时通过 `python -m backend.storage.cloud_sync --configure-stdin` 的标准输入传入 JSON，不使用命令行参数携带秘密。

手动上传已有数据：`python -X utf8 -m backend.storage.cloud_sync --force`。此命令不扫描邮箱、不调用模型。成功必须经过独立读回并核对 SHA-256；结果保存在运行目录 `cloud-sync-status.json`。失败保留云端上一份数据，下次重试，不影响本机邮件处理。

本机页面服务下次启动后，每分钟检查一次数据变化并上传；现有自动/手动扫描结束后也尝试上传。无需新增 Windows 任务。电脑关闭后，网站继续提供最后同步的副本。当前运行的旧服务不会被开发过程强制重启。

在线页面每分钟读取云端副本，底部显示最后同步时间。所有修改接口由服务端拒绝，勾选、编辑、扫描、重启和退出操作仅在本机可用。不同邮箱切换后同步当前选中的邮箱台账，云端只保留最新一份快照。访问权限保持 Site 所有者私有。
